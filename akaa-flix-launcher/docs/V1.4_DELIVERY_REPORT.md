## Changes

## Android limitations

- Google TV offers no Home-app chooser. Granting the HOME role there needs Shizuku or one ADB command
  (`adb shell cmd role add-role-holder --user 0 android.app.role.HOME com.akaaflix.launcher`); some Google TV
  builds keep sending Home to their own launcher unless it is disabled
  (`adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx`, undo with `pm enable`).
- After uninstalling and reinstalling the launcher, Android 10+ no longer lets it read the old
  Download/AkaaFlix files by itself; use *Other file…* with a file manager, or restore before uninstalling.
