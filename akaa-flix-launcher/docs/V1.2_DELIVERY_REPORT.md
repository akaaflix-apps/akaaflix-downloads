## 1. Bugs identified

| # | Bug | Cause found in the code |
|---|---|---|
| B1 | Play Store shown twice | The launcher never creates entries, and it already kept one entry per package **per user profile**. Both cards in the screenshot carry the same name (they sort next to each other), so the second entry is either the **same Play Store from another Android user profile** (Android 14 / Xiaomi "dual apps" clone profiles are returned by `UserManager.userProfiles`) or a second package with the same name. Both cases are now removed (§2). The white card is Google Play Store's official Android TV banner; it is shown because "Use TV banners" is on |
| B2 | Default-launcher state partly assumed | Status came from `resolveActivity(HOME)` only; the Android 10+ HOME role holder and the device's other Home apps were not considered, and Google TV firmwares (no chooser) were not detected |
| B3 | Misleading "Start with device" switch | It was shown on Android 10+ where Android forbids it, with the text "Android 6–9", which read like a compatibility limit. Nothing verified whether start-up actually worked |
| B4 | No real management of pre-installed apps | Only uninstall of user apps and the App info screen; no inventory of all packages, no disable / enable / remove-for-user / restore |
| B5 | Device information rounding | Refresh rate truncated (59.94 Hz shown as 59), only the first CPU ABI, no available RAM / free storage |

## 3. Works without additional permissions

Dynamic app discovery and launch (LauncherApps / PackageManager), duplicate removal, real Home status,
official default-launcher selection (role dialog / Home settings, where the firmware offers it), start-up
verification, uninstall of user apps (Android's confirmation), App info screen (where Android offers Disable /
Uninstall updates if the device allows), complete package inventory, device information, diagnostics,
remote navigation and neon focus.

## 4. Requires Shizuku, ADB, root or device-owner provisioning

| Feature | Requirement |
|---|---|
| Disable / enable pre-installed apps directly | Shizuku (ADB or root) – or ADB command shown; or App info when the firmware allows |
| Remove a pre-installed app for the current user / restore it | Shizuku or ADB (`pm uninstall -k --user 0`, `pm install-existing`) |
| Uninstall updates of a pre-installed app directly | Shizuku on Android 10+ (`pm uninstall-system-updates`); otherwise App info |
| Make Akaa Flix the default Home on firmwares without a chooser (Google TV, many Xiaomi boxes) | Shizuku or ADB (`cmd role add-role-holder … android.app.role.HOME`); optionally disabling the stock launcher |
| Permanent removal of system packages from the system partition | Root / OEM firmware only – not offered |
| Fleet-wide hiding of apps | Device-owner provisioning (not implemented; would add device-admin components) |
| Shizuku itself on Android 6.0 | Not supported by the Shizuku API library in this launcher (Android 7.0+); ADB commands are shown instead |

Akaa Flix never grants itself `DELETE_PACKAGES`, root or device-owner rights; Shizuku must be started by the
user and must be restarted after each reboot unless the device is rooted.

## 7. Remaining limitations

- Whether this Xiaomi firmware accepts a third-party HOME role holder can only be seen on the device; the
  status rows report Android's answer and never assume success.
- Shizuku (non-root) stops at every reboot; disabled / removed packages stay that way, but new privileged
  actions need Shizuku running again.
- `QUERY_ALL_PACKAGES` was added for the full package list (install-time permission; Google Play restricts
  it, sideloaded builds are not affected).
- Storage per app shows the APK size; data/cache sizes need the usage-access special permission, which is not
  requested.
