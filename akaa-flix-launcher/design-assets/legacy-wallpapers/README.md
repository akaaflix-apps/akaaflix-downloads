# Legacy wallpapers (v1.0)

Original procedural renders that formed the selectable collection in v1.0.x
(`tools/generate_wallpapers.py`). Since v1.1 the selectable library contains only the approved
collection (Egyptian Pyramids Cinematic default, Animated Neon Pulse and the wallpapers extracted
from `design-assets/wallpapers/akaa-flix-wallpapers.pdf`), so these files are no longer packaged in
the APK. They are kept here unchanged, not deleted.
